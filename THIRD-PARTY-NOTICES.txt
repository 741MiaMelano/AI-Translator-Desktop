Optional song/music classifier
------------------------------

inaSpeechSegmenter speech/music/noise model and architecture — MIT
Source: https://github.com/ina-foss/inaSpeechSegmenter/tree/7a41b809c3cc6d8d36b24e70784779f8d16f7b5e

The optional classifier downloads the pinned 3.1 MiB model only after user
confirmation. The application loads the original Keras weights in an
equivalent PyTorch network so it can reuse the existing local runtime without
shipping TensorFlow. Signal feature extraction follows SIDEKIT and is covered
by LGPL-3.0-or-later; the adapted Python source remains readable and
replaceable in the package.
