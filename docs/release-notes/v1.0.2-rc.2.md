# Desktop AI Translator 1.0.2-rc.2 / 桌面 AI 翻译器 1.0.2-rc.2

Status: **unsigned open-source test release / 无签名开源测试版**

## 中文

- 项目列表收敛为单一进入入口；项目概览默认显示修改配置、归档、重新翻译和删除，普通流程不再展示开发维护工具。
- 本地语音识别增加基于 PCM 静音证据的词级边界修正，拉丁语字幕按完整单词分段；字幕编辑器使用真实媒体时钟同步预览。
- 修复 Windows 较长用户数据目录下 Whisper 首次转写失败：后台直接使用已校验的模型绝对路径，并在每个唯一任务目录内使用短输出名，不增加任何用户设置。
- 翻译契约升级为 `translation.structured.v6`：后台按完整语义单元理解连续字幕，同时保持原字幕 ID 与时间码，并拒绝空白译文。
- 黄仁勋英语素材及两份真实韩语素材共 38 段使用 DeepSeek v4 flash 完成真实回归；全部非空、无交付阻断，导出时间码与修复前基线逐段一致。
- 完整自动化检查、安装版和便携版构建、安装/升级/卸载回归及候选文件 SHA-256 校验均作为发布门槛。

此版本可以用于公开测试，但不是面向普通用户承诺稳定性的正式版本。它没有 Windows Authenticode 签名，系统可能显示 **Unknown publisher** 或 SmartScreen 提示。请只从项目官方仓库获取，并在运行前核对 SHA-256；自愿体验者应先备份重要项目。

## English

- Reduced the project list to one entry action and kept the few lifecycle actions visible on the project overview while removing maintenance tools from the normal workflow.
- Added PCM-silence evidence to refine local ASR word boundaries, preserved whole Latin words during segmentation, and connected subtitle preview to the real media clock.
- Fixed first-run Whisper failures under long Windows user-data paths by using the verified absolute model path and a short output name inside each unique operation directory, with no new user-facing setting.
- Upgraded translation to `translation.structured.v6`: adjacent captions are understood as semantic units while original caption IDs and timings stay fixed, and blank target captions are rejected.
- Completed real DeepSeek v4 flash regression on one English and two Korean media projects (38 captions total); every caption remained non-empty, delivery had no blockers, and exported timings matched the baseline cue by cue.
- Full automated checks, installer and portable builds, install/upgrade/uninstall regression, and SHA-256 verification remain release gates.

This build may be shared for public testing, but it is not a stable release intended for non-technical users. It has no Windows Authenticode signature, so Windows may show **Unknown publisher** or a SmartScreen warning. Download it only from the official project repository, verify its SHA-256 before running, and back up important projects first.
