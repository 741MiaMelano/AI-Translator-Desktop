# Desktop AI Translator 1.0.2-rc.4 / 桌面 AI 翻译器 1.0.2-rc.4

Status: **P0 + P1 + P2 frozen baseline / P0 + P1 + P2 冻结基线**

## 中文

- 翻译上下文按字幕句界自适应扩展，并为完整项目生成受限、确定性的只读提要；上下文继续受 token 预算和缓存指纹约束。
- 校对工作台加入完整音频波形、1–12 倍缩放、点击定位和拖动字幕起止边界，所有修改继续复用原有时间轴命令、撤销和持久化流程。
- 批量队列加入持久化的“设为下一项”优先级；排队数、运行数和可调度任务直接可见，运行中的任务不会被抢占。
- 术语库支持从项目字幕提取高频候选，并支持 CSV/TSV 导入、重复项跳过、保存重开及带 BOM 的中文导出。
- 根据人工验收修复字幕表格列宽与溢出，统一“撤销修改 / 恢复撤销”文案，并将字幕样式中的字体、字号、颜色、描边和阴影改为受控选项。
- P0、P1、P2 专项验收、完整自动化检查、真实素材验证以及 Windows 安装版和便携版发行门禁全部通过。

该版本是后续 ASR、VAD 和界面演进前的可回退基线，不承诺正式稳定版兼容性。Windows 构建仍无 Authenticode 签名，可能显示 **Unknown publisher** 或 SmartScreen 提示。请只从项目仓库获取，并在运行前核对 SHA-256。

## English

- Expanded translation context along subtitle sentence boundaries and added a bounded, deterministic read-only project summary, both covered by token budgeting and cache fingerprints.
- Added full audio waveforms, 1–12x zoom, seek-on-click, and draggable subtitle boundaries while preserving the existing timeline-command, undo, and persistence paths.
- Added durable “run next” queue priority with visible queued/running counts; active work is never preempted.
- Added frequent-term extraction plus CSV/TSV glossary import, duplicate skipping, persistence, and BOM-safe Chinese export.
- Addressed acceptance feedback with bounded subtitle-table columns, clearer undo labels, and controlled subtitle-style choices for fonts, sizes, colors, outlines, and shadows.
- P0/P1/P2 acceptance, the complete automated suite, real-material checks, and Windows installer/portable release gates passed.

This is the rollback baseline before further ASR, VAD, and interface work, not a stable-release compatibility promise. Windows artifacts remain unsigned and may trigger **Unknown publisher** or SmartScreen warnings. Download only from the project repository and verify SHA-256 before running.
