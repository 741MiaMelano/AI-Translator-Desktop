# Desktop AI Translator 1.0.2-rc.5 / 桌面 AI 翻译器 1.0.2-rc.5

Status: **updated release candidate / 已更新候选版本**

## 中文

- 本地 Whisper.cpp 扩展为 Small、Large V3 Turbo 与 Large V3 共六种受信模型变体，支持校验下载、暂停/续传、手动导入和独立安装状态。
- 全局默认、项目覆盖和实际运行模型分别持久化；运行记录包含模型哈希、实际 CPU/CUDA 设备和生效 VAD 配置。
- 接入 Silero VAD 自动、关闭和有界自定义模式，并保留明确的 CUDA 回退与失败状态。
- 重排语音识别模型页；模型卡选择同时作为全局默认和下载/导入/卸载目标，卸载先二次确认，ASR 请求运行期间由后端拒绝。
- 修复翻译服务商/模型全局保存、DeepSeek 首次自动验证、拉取模型列表恢复，以及安装 ASR 模型后继续被阻断的问题。
- 修复多服务商状态并存时旧失败记录阻断当前未验证服务商的问题；未手动测试的已保存配置显示为“可用”，首次翻译时再真实验证。
- 修复 ASR 失败后切换模型重试仍复用旧状态、字幕光标拆分无效及自动处理循环超过安全步数的问题。
- 增加全局目录原生选择和模型/运行时一键迁移；迁移完成后安全重启并修复 Qwen Python home。
- Qwen3-ASR 支持中文模型路径，已完成 CUDA runtime 探测与真实短音频转写。
- 六模型 CPU/真实 CUDA、Auto、480 秒长视频、完整自动化检查和 Windows 候选打包门已通过；最终人工复验未发现阻塞问题。

已知边界：大模型不随基础安装包分发；现有授权素材不足以给全部模型计算同语言 CER/WER 或覆盖日文、粤语与重叠说话；Windows 构建仍无 Authenticode 签名。

## English

- Expanded the trusted local Whisper.cpp catalog to six Small, Large V3 Turbo, and Large V3 variants with verified download, pause/resume, manual import, and independent install state.
- Persisted global defaults and project overrides separately while recording the actual model hash, CPU/CUDA device, and effective VAD configuration for each run.
- Added Silero VAD automatic, off, and bounded custom modes with explicit CUDA fallback and failure states.
- Simplified model management so the selected card is the single global/action target; uninstall requires confirmation and is rejected by the backend while an ASR request is active.
- Fixed durable provider/model selection, first-use DeepSeek validation, fetched-model restoration, and workflow recovery after installing a missing ASR model.
- Fixed mixed-provider readiness ordering so an older failed provider cannot block a saved provider awaiting first-use verification; the global indicator now says available instead of claiming a connection test passed.
- Fixed stale ASR retry state after model changes, cursor-based subtitle splitting, and automatic-workflow safety-loop exhaustion.
- Added native global-directory pickers and verified model/runtime transfer with safe restart and Qwen Python-home repair.
- Added Qwen3-ASR support for Unicode model paths and verified a real CUDA transcription.
- Passed the six-model CPU/CUDA matrix, Auto selection, an eight-minute video run, complete automated checks, Windows packaging gates, and final user acceptance.

Known boundaries: large models remain separate downloads; available authorized material does not support a complete CER/WER ranking or Japanese, Cantonese, and overlapping-speaker coverage. Windows artifacts remain unsigned.
