# Desktop AI Translator 1.0.2-rc.3 / 桌面 AI 翻译器 1.0.2-rc.3

Status: **P0 + P1 frozen baseline / P0 + P1 冻结基线**

## 中文

- 统一单文件与批量导入入口；自动匹配明确的媒体和字幕，只在编码、匹配或源时间轴存在真实风险时要求确认。
- 完成校对工作台 V1：播放器与字幕定位联动，支持时间微调、设置起止点、撤销/重做、问题筛选与批准导出。
- 字幕样式、导出预设、风格指南和术语库改为可直接操作的结构化界面，高级 JSON 仍作为兼容入口保留。
- “项目”和“批量处理”共享选择模式与批量操作，可按任务能力开始、继续、暂停或停止，并通过项目回收站安全删除和恢复。
- 新增唯一“媒体工具”入口，复用现有项目能力完成音频提取、内嵌字幕提取、语音识别和字幕校时。
- 修复批量页两个交互遗漏：导入后默认显示全部项目；项目移入回收站后不再残留于当前批次或高级任务列表。
- P0、P1 专项端到端验收、完整自动化检查及 Windows 打包态媒体、ASR、设置、持久化和退出流程均通过。

该版本是进入 P2 前的可回退基线，不承诺正式稳定版兼容性。Windows 构建仍无 Authenticode 签名，可能显示 **Unknown publisher** 或 SmartScreen 提示。请只从项目仓库获取，并在运行前核对 SHA-256。

## English

- Unified single-file and batch imports, auto-matching unambiguous media/subtitle inputs while pausing only for real encoding, matching, or timeline risks.
- Completed the V1 proofreading workbench with synchronized playback, timing edits, undo/redo, issue navigation, approval, and export.
- Replaced raw resource payloads with structured subtitle-style, export-preset, style-guide, and glossary controls while retaining advanced JSON compatibility.
- Shared project selection and bulk actions across the project and active-batch views, including capability-aware task control and recoverable project deletion.
- Added one Media Tools entry that reuses existing project workflows for audio extraction, embedded subtitles, ASR, and subtitle timing.
- Fixed two batch-view regressions: imported projects are visible before selection, and trashed projects no longer remain in the active batch or advanced task list.
- P0/P1 acceptance, the complete automated suite, and packaged Windows media, ASR, settings, persistence, and exit-flow smoke tests passed.

This is the rollback baseline before P2, not a stable-release compatibility promise. Windows artifacts remain unsigned and may trigger **Unknown publisher** or SmartScreen warnings. Download only from the project repository and verify SHA-256 before running.
