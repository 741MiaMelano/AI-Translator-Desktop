# Desktop AI Translator 1.0.2-rc.6 / 桌面 AI 翻译器 1.0.2-rc.6

Status: **updated release candidate / 更新候选版**

## 中文

- 改进长视频 ASR 的缓存、异常时间戳修复、字幕分段容错与错误诊断。
- 增加对话人声分离以及歌曲/唱词高置信度过滤流程，模型仍按需下载，不随安装包分发。
- 优化视频预览、字幕定位、进度条拖动与字幕样式实时预览。
- 改进翻译服务商拒绝请求、响应格式异常与批次失败时的原因展示和安全重试。
- 清理发布内容；源码仓库不包含用户项目、密钥、数据库、缓存或下载模型。

## English

- Improved long-video ASR caching, malformed timestamp repair, subtitle segmentation fallback, and diagnostics.
- Added optional dialogue-vocal separation and high-confidence song/lyric filtering; downloadable models remain outside the application package.
- Improved video preview, subtitle navigation, seeking, and live subtitle-style preview.
- Improved provider rejection, response-schema, and batch-failure diagnostics with safe retry behavior.
- Cleaned the release boundary: the source repository excludes user projects, credentials, databases, caches, and downloaded models.
