# Desktop AI Translator 1.0.2-rc.7 / 桌面 AI 翻译器 1.0.2-rc.7

## 中文

- 发布当前桌面端源码的干净快照，保留应用主体、构建配置、测试和运行所需的受校验资源。
- `AI-Translator-Desktop.exe` 作为独立 Release 附件提供，不进入 Git 历史。
- 源码包不包含用户数据、凭据、模型、缓存、构建目录、历史截图或本地依赖目录。
- 便携启动器会校验官方 EXE 的 SHA-256；源码树中的本地构建不套用官方附件哈希。

## English

- Publishes a clean snapshot of the current desktop source, retaining the application, build configuration, tests, and verified runtime resources.
- Provides `AI-Translator-Desktop.exe` as a standalone Release asset rather than storing it in Git history.
- Excludes user data, credentials, models, caches, build output, historical screenshots, and local dependency directories.
- The portable launcher verifies the official EXE SHA-256; locally built executables are not compared with the release-asset hash.

## Release assets

- `AI-Translator-Desktop.exe`
- `AI-Translator-Desktop.exe.sha256`
