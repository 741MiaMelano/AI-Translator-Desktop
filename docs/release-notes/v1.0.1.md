# Desktop AI Translator 1.0.1 / 桌面 AI 翻译器 1.0.1

Status: **final unsigned open-source release / 正式无签名开源版本**

## 中文

此版本提供两种 Windows x64 使用方式：免安装 Portable EXE，以及传统的
单用户安装包。仓库根目录的 `启动便携版-Start-Portable.bat` 会在首次运行时
从本项目的官方 GitHub Release 下载 Portable EXE、校验固定 SHA-256，并在
后续直接离线启动。

项目公开内容已精简为应用源码、运行与构建资源、自动化测试、用户文档和
许可证材料；内部阶段计划、交接、审计过程、基准原始结果和讨论文档不包含
在公开版本中。

本版本没有 Authenticode 签名。Windows 会显示 **Unknown publisher**，并可能
显示 SmartScreen 提示。请只从官方仓库下载，并在运行前核对 SHA-256。

## English

This release provides two Windows x64 options: a no-install Portable EXE and a
traditional per-user installer. `启动便携版-Start-Portable.bat` in the repository
root downloads the Portable EXE from the official GitHub Release on first run,
verifies its pinned SHA-256, and starts the cached copy directly on later runs.

The public repository is reduced to application source, runtime/build assets,
automated tests, user documentation, and license material. Internal planning,
handoff, audit-process, raw benchmark, and discussion documents are not part of
the public snapshot.

This release is not Authenticode-signed. Windows reports **Unknown publisher**
and may display SmartScreen. Download only from the official repository and
verify SHA-256 before running it.
